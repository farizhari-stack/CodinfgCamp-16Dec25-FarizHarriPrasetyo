## ✨ Overview

The **Neural Matrix Dashboard** is more than just a to-do list; it's a centralized hub for productivity. Built with a focus on visual excellence and high-performance interaction, it allows "Operatives" to manage tasks, track focus sessions, and access external nodes via a sleek, futuristic interface.

---

## 🌟 Key Features

### 🧠 **Neural Dashboard Hub**
*   **Custom Neural Modals**: Replaced generic browser dialogs with animated, glassmorphism pop-ups for all user inputs.
*   **Dynamic Greetings**: Time-aware greetings (Morning/Afternoon/Evening) with a customizable "Operative" designation.
*   **Persistent Matrix**: All tasks, links, and settings are saved automatically using the **Browser Local Storage API**.

### ⏱️ **Neural Focus Module**
*   **Pomodoro Engine**: Fully functional focus timer with custom duration support.
*   **Visual Feedback**: Circular progress tracking with neon glow effects.
*   **Session Alerts**: Custom neural alerts when a focus session concludes.

### 📝 **Daily Objectives (To-Do List)**
*   **Smart Sorting**: Automatically keeps active objectives at the top for maximum focus.
*   **Edit Matrix**: Double-click any objective to refine its parameters via a modal.
*   **Duplicate Prevention**: Built-in verification to prevent redundant objective transmission.

### 🌗 **Theme Synchronization**
*   **Dark/Light Toggle**: Seamlessly switch between a deep cyberpunk slate and a high-readability light blue theme.
*   **Adaptive UI**: All text, icons, and input fields adapt their contrast and colors for perfect visibility in both modes.
